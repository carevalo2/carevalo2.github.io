# Repo for our final project’s GitHub Pages

## Links

- [Our crash-reporting repo](https://github.com/carevalo2/crash-reporting)
- [Live site](https://carevalo2.github.io/)

Just make sure you do this when you’re working on your part:

- Pull the latest changes before you start.
- Fill in your part in `final-project.ipynb`, then run and save the notebook.
- Export it as `index.html` and commit and push both files.

Once your changes are on main the live site is going to update on its own.
